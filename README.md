# Client World Edit 1.12.2

Mod de Minecraft que da herramientas de edición de mundo estilo WorldEdit **instalándolo solo en el cliente**: no hace falta tenerlo en el servidor.

![Minecraft](https://img.shields.io/badge/Minecraft-1.12.2-62B47A)
![Forge](https://img.shields.io/badge/Forge-14.23.5.2859-DF5B2D)
![Licencia](https://img.shields.io/badge/licencia-MIT-lightgrey)

## Compatibilidad

| | Versión |
|---|---|
| Minecraft | 1.12.2 |
| Forge | 14.23.5.2859 |
| Mod | 1.1.0 |

## Instalación

1. Instalá [Forge 1.12.2 (14.23.5.2859)](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.12.2.html).
2. Bajá `ClientWorldEdit-1.1.0.jar` desde [Releases](https://github.com/themortamc/Client-World-Edit-1.12.2/releases/latest).
3. Copialo a la carpeta `mods` de tu instalación de Minecraft y abrí el juego con el perfil de Forge.

No instales nada en el servidor: el mod funciona solo del lado del cliente.
